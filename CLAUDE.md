# SmartPlan — правила работы с репозиторием

## Фактический стек

- Electron
- JavaScript без фреймворка
- Canvas 2D, Three.js и jsPDF
- тесты через `node:test`

Не предполагать наличие React, Vite или TypeScript.

## Обязательные проверки

Перед публикацией изменений выполнить:

```bash
npm ci
npm run check
npm run build-web
npm run build-win
```

## Архитектурные границы

- Физические размеры должны оставаться неизменными при смене масштаба отображения.
- Изменение проекта должно попадать в undo/redo и запускать автосохранение.
- Сырые данные файла нельзя передавать в `executeJavaScript` или вставлять в HTML без экранирования.
- Чтение и запись файлов выполняются только через ограниченный IPC в `preload.js`.
- Формат проекта `version: 3` сохраняется для совместимости; изменения модели отмечаются через `modelRevision` и миграции.
- `index.html` остаётся общей оболочкой для Electron и веб-версии; браузерная логика разделена по назначению в `renderer/`, стили находятся в `styles.css`.
- Веб-версия должна работать из относительного каталога и собираться командой `npm run build-web` без Electron API.

## Релизы

- Версия берётся из `package.json`.
- Windows-архив: `SmartPlan-{version}-win.zip`.
- GitHub Actions публикует архив при теге `v*` только после успешных проверок.
